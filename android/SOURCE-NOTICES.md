# Android source provenance

Process components are adaptations of the user's live Process source project. Their original resources are preserved byte-for-byte; reusable preview modules omit Firebase credentials and host services.

The native Pad XY adapts TenKPositionalPadSliderDemo.swift and TenKPositionalPadSliderPhotosStylePositionPad.swift. Original source notices: created by Balaji Venkatesh on 26/03/26 and 27/03/26. Reference: the archived 10K Design catalog component design-position-pad. Those notices are retained in the Kotlin sources and exported package.

The typewriter remains a private prototype outside the selected 200-entry catalog. All Android components remain development previews until their declared checks pass.

AnimatedStateButton (AnimatedButton.swift, Spinner.swift, ContentView.swift), created by Balaji Venkatesh on 18/03/25, is adapted by TenKAsyncButton. AMReactionView, created by Balaji Venkatesh on 22/08/26, is adapted by TenKReactionPicker. Original notices are retained in the Kotlin sources.

BTSlider (TenKBTSliderDemo.swift and TenKBTSliderCircularSlider.swift), created by Balaji Venkatesh on 05/09/26, is adapted by TenKSleepSlider. The notices are retained in sources and the exported library.

FWTransition (28/08/26) and InternetConnectivity (16/04/25), original source by Balaji Venkatesh, are adapted by TenKFlipTransition and TenKNetworkMonitor. Notices retained in source and package.

Skeleton (12–13/04/25) and iPCoverflow (05/05/26), original source by Balaji Venkatesh, are adapted by TenKSkeleton and TenKCoverFlow. The original WWDC image is unchanged. The original CoverFlowReflection.metal is retained as a parity reference, not compiled as Android code. Notices retained in source and exported packages.
