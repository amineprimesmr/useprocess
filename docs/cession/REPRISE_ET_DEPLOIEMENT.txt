PROCESS — REPRISE TECHNIQUE

Ce pack est un état de travail interne, pas une release App Store certifiée.
Aucune donnée personnelle de production ni clé privée serveur n'est exportée.
Les configs client absentes ont leurs templates ; les remplir sous les droits
appropriés sans couper les anciennes versions encore en circulation.

Architecture
App SwiftUI → Firebase Auth (Apple / invité) → Firestore.
App → RevenueCat / StoreKit pour achats → entitlement premium.
Coach → Cloud Functions → vérification RevenueCat → Anthropic.
App/site → PostHog ; attribution SDK AppsFlyer.
Support → email contact@useprocess.xyz ; webhook et tâche planifiée Crisp supprimés.
Affiliés → Firebase + email Hostinger ; versements manuels.
Site Vite/React → Vercel ; domaine et mail chez Hostinger.
Médias originaux → Storage useprocess-d4385.firebasestorage.app/media.
MCP affilié → /api/mcp sur Vercel → affiliateMcp, tokens individuels.

Connexions supplémentaires trouvées
- WhatsApp support personnel codé dans website/src/affiliate/affiliate-utils.js :
  remplacer par le numéro de support repreneur lors du transfert convenu.
- Documentation Telegram clippers dans le checkout : ownership, participants,
  bot et liens à inventorier séparément ; aucun bot facturé confirmé.
- TikTok OAuth : sources présentes mais aucune variable TIKTOK_* constatée dans
  les environmentVariables des fonctions listées. Ne pas annoncer ce service
  comme configuré/opérationnel sans validation.
- App Check : aucun ENFORCE_APP_CHECK trouvé dans ces variables déployées.
  Dépendance de sécurité et réglages à vérifier, sans activer brutalement une
  protection qui pourrait bloquer l'app publiée.
- Les scopes API Apple/RevenueCat et clés client AppsFlyer peuvent couvrir
  d'autres projets : transférer le projet, pas l'ensemble du compte personnel.

Déploiements
Backend : depuis la racine, npm --prefix firebase/functions ci,
  npm --prefix firebase/functions run build, puis tests du package.
  Firebase minimal : firebase deploy --project useprocess-d4385
  --only functions:<noms concernés>. Le predeploy configure la compilation TS.
  Règles/indexes seulement si modifiés, après tests et validation de compatibilité.
Site : cd website ; npm ci ; npm run build.
  Relier le projet Vercel de l'acquéreur avant déploiement sous ses droits.
  Le dossier .vercel du vendeur est exclu : ne pas déployer par erreur chez lui.
  Vérifier pages légales, API rewrite, AASA, domaines et adresses email.
iOS : restaurer packages via Package.resolved, renseigner équipe/signing,
  profils et capabilities ; conserver bundle et produits historiques.
  Aucun simulateur ; utiliser l'iPhone 14 Pro Max physique de cette session.
  Une compilation à la fois, nice -n 15 et xcodebuild -jobs 1.
  Ne pas réutiliser les scripts historiques de pricing sans comprendre leurs effets.
